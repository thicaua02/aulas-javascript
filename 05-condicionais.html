Comandos Condicionais

São estruturas de controle de flexo que permitem que o código tome decisões.

Elas funcionam avaliando uma expressão lógica (condição) que resultam em verdadeiro (true) ou falso (false).

Com base nesse resultado, nosso script toma uma decisão e executa as ações conforme o resultado.

Exemplos de cenários que envolvem lógica condicionais:

  • Processo de login: dados certos? entra... errados? não entra!
  • Vitrine de produtos: tem estoque? mostra o produto... senão, não mostra
  • Cadastro de senha segura: o valor digitado atende os critérios? se sim, efetiva o cadastro... senão, não efetiva.
