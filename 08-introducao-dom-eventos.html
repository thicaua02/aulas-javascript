Exemplos de DOM e Eventos

DOM (Document Object Model): modelo de objetos do documento, ou seja, a estrutura da página HTML representada como objetos que o JS pode acessar e manipular.

Para acessar elementos do DOM, o JS utiliza funções/métodos especificos de seleção. E a partir da seleção do elemento, o JS permite (atraves de outras funções e propriedades) realizar manipulações de diversos formas. Exemplos:

  • Menu responsivo/hamburger
  • Modo Escuro (Dark/Light)
  • Validação personalizadas/avançadas de formulário
  • Janela Modal (caixa de dialogo)
  • Galerias de imagem, sliders/carroseis de conteúdo
